# 🌐 Week 02 – Computer Networking

## 📖 Overview

Networking is one of the core foundations of DevOps. Before learning Docker, Kubernetes, Cloud, and CI/CD, it's important to understand how computers communicate over a network.

During this week, I learned the fundamental networking concepts required for DevOps and practiced Linux networking commands used for troubleshooting and system administration.

---

## 📚 Topics Covered

- Computer Networks
- Types of Networks (LAN, MAN, WAN)
- OSI Model
- TCP/IP Model
- IP Addressing
- Public vs Private IP
- IPv4 vs IPv6
- MAC Address
- DNS
- DHCP
- Ports & Protocols
- HTTP & HTTPS
- TCP vs UDP
- SSH
- Routing
- Linux Networking Commands

## 🎯 Learning Outcomes

By the end of this week, I can:
