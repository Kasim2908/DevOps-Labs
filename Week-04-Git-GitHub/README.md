# 📖 Overview

Git is the industry-standard distributed version control system used by developers and DevOps engineers to track code changes, collaborate efficiently, manage releases, and maintain project history.

This week focused on building a strong understanding of Git fundamentals, GitHub collaboration, branching strategies, advanced Git commands, and real-world workflows used in professional software development.

---

# 🎯 Learning Objectives

By completing this module, I learned how to:

- Configure Git for local development
- Track and manage source code efficiently
- Work with branches and merge strategies
- Resolve merge conflicts
- Collaborate using GitHub
- Use Pull Requests and GitHub Flow
- Recover from mistakes using advanced Git commands
- Apply Git best practices followed in DevOps teams

# 💡 Key Takeaways

- Git is a distributed version control system.
- Branching enables isolated feature development.
- Pull Requests improve collaboration and code quality.
- Git Rebase creates a cleaner project history.
- Git Reflog helps recover lost commits.
- Git Reset and Git Revert serve different recovery purposes.
- Following Git best practices leads to maintainable and collaborative workflows.
