# 📚 Week 04 – Git & GitHub

## 📖 Overview

Version Control is an essential skill for every Developer and DevOps Engineer. Git is the most widely used distributed version control system, helping teams collaborate, track code changes, manage project history, and deploy applications efficiently.

During this week, I learned Git fundamentals, GitHub workflows, branching strategies, collaboration techniques, and best practices used in real-world software development and DevOps.
